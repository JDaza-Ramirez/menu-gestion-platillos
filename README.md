# Menú Interactivo - Sistema de Gestión de Platillos

Aplicación construida con Vanilla JS que permite gestionar un catálogo gastronómico con persistencia en LocalStorage y filtrado dinámico.

Validación de formularios con Regex:

- Filtrado por categorías dinámicas.
- Persistencia de datos (CRUD).
- Diseño responsive con CSS Grid/Flexbox.

**Tecnologías:** JavaScript (ES6+), HTML5, CSS3.
